# 环境文件键名清单（只列键名，不含值）。文件位置 ~/.config/memory-hub/{staging,prod}.env，权限 0600，目录 0700。
# 必填
MEMORY_HUB_HOME            数据目录（内含 memory-eternal.db、backups/）
MEMORY_HUB_HOST            监听地址；本部署固定 127.0.0.1
MEMORY_HUB_PORT            staging=7991；切换后=7990
# 切换后（nginx 反代 /memory/）必填
MEMORY_HUB_BASE_PATH       /memory
MEMORY_HUB_TRUST_PROXY     1（按 X-Forwarded-For 区分来源；否则同机反代下所有客户端共用一个失败限流桶）
MEMORY_HUB_ALLOWED_HOSTS   经 nginx 访问时 Host 头的主机名（逗号分隔；不含端口）
MEMORY_HUB_ALLOWED_ORIGINS 管理界面登录/写操作的 Origin 白名单（逗号分隔，含协议）
# 蒸馏（缺一则降级为原文卡）
MEMORY_LLM_BASE_URL
MEMORY_LLM_MODEL
MEMORY_LLM_KEY             只能放在 0600 环境文件里
# 蒸馏可选参数（见 docs/deployment-config.md）
MEMORY_LLM_REASONING_EFFORT  none|low|medium|high，空=不传；58 生产=none
MEMORY_LLM_EXTRA_BODY        JSON 对象字符串，合并进请求体（可选）
MEMORY_LLM_TIMEOUT_MS        单次超时毫秒，默认 90000（可选）
# 其它
NODE_NO_WARNINGS           1（屏蔽 node:sqlite 的 ExperimentalWarning）
MEMORY_HUB_LOG_LEVEL       info（默认）
