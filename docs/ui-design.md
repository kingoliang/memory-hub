# 管理界面设计说明（v3 · Swiss 国际主义风格）

范围：只涉及 `web/`（纯静态，无构建、无第三方依赖、无外部 CDN）。后端 API、哈希路由、数据格式未改。v3 把 v2 的视觉按 Swiss 设计稿重做：五个主页面（总览 / 卡片 / 待审 / 整理 / 图谱）+ 次要页面（回收站 / 标签 / 健康 / 活跃度 / 令牌 / 审计 / 账户）+ 设置页。设置页新增了后端接口 `GET/PATCH /admin/api/settings`，其余仍沿用原 API。
设计依据：ui-ux-pro-max（第三方 skill，本机安装在 `~/.claude/skills/ui-ux-pro-max`）的检索结果 + 其 UX 规则清单，再按本项目约束取舍。

## 1 方向与取舍（v3 Swiss）

- 风格：12 列网格思路、左对齐、大留白；层级只靠字号与字重；1px 墨色硬分隔线 + 3px 粗线做分区顶边；**无圆角 / 阴影 / 渐变**；编号（01–12 导航、A1/B1/C1 分区、1–4 步骤、列表序号）与大号数字做视觉锚点；白 / 近黑底 + **单一强调色 #E30613**（深色 #FF5560）。ok / warn / bad 仅用于状态。
- 字体（自托管，woff2 在 `web/fonts/`，OFL，见 `fonts/README.txt`）：**Archivo**（无衬线，400/500/700/800）正文与标题；**IBM Plex Mono**（400/500）用于编号、标注、路径、数字标签。中文走系统 CJK 字体栈（苹方 / 思源黑体 / 微软雅黑），不内置。无外部 CDN（CSP `font-src 'self'`）。
- 取舍：移动端画板用响应式 CSS 体现，不单独建页面。页头编号与导航编号一致（01 总览 … 10 设置 … 13 审计）。

## 2 令牌（styles.css 第 1 节）

- 颜色：`--bg/--surface/--surface-2/--surface-3`、`--line/--line-strong/--line-input`、`--text/--muted/--faint`；语义色 `accent/teal/ok/warn/bad/purple/pink/cyan`，每个都有 `-soft` 底色。类型色点 `--k-*` 与图谱节点色一致。
- 间距 4px 栅格 `--sp-1…8`；圆角令牌 `--r*` 全部为 0（并有全局 `border-radius: 0` 兜底）；`--shadow-*` 为 none；字号 `--fs-xs…lg`；阴影 3 级；z 层级 `--z-*`；动效 `--dur-fast/--dur/--ease`。
- 对比度：正文/次要/提示文字在各表面上 ≥ 4.5:1；语义色文字在其 `-soft` 底上 ≥ 4.5:1；输入框边框 ≥ 3:1。用 `/private/tmp/mh-ui/contrast.py` 的同一算法复核过（该脚本不在仓库内）；改令牌后须重算。
- 暗色：色调偏亮的低饱和变体，而非简单反色，两套主题单独验证。

## 3 主题

默认跟随系统；顶栏按钮循环 跟随系统 → 浅色 → 深色，选择只存浏览器 `localStorage`（不可用时静默退化）。`theme-init.js`（经典脚本，CSP 同源允许）在首帧前应用，避免闪烁。图谱画布通过 `mh-theme` 事件重读 CSS 变量。

## 4 组件与状态

- 按钮：主/次/幽灵/危险/危险幽灵，36px（触屏 44px）；hover、active、disabled、`aria-busy`；被点击按钮显示转圈（`data-spin`，纯视觉）。
- 表单：统一 38px 控件、焦点环 3px；状态筛选用分段选择器（真实 radio，选中即应用）；已生效筛选显示为可移除的芯片。
- 反馈：提示条（info/ok/warn/bad，可带操作）、toast（`aria-live`，进入动画）、模态框（焦点陷阱 + Esc，手机端为底部抽屉）。
- 三态：加载 = 状态文字 + 骨架；空 = 图标 + 说明 + 下一步按钮；错误 = 原因 + 重试按钮。
- 表格窄屏折成"标签：值"卡片；卡片行整行可点（标题链接伪元素铺满，勾选框/标签/按钮在其上）。

## 5 页面层次

- **总览**：A1 待审大数字（强调色）+ 去审核按钮 + 键帽提示，A2 提醒（需处理常驻、提示折叠）→ B1–B5 编号指标格（卡片总数 / 回收站 / 标签 / 库大小 / 备份）→ C1 近 30 天柱状列、C2 类型分布 → D1 署名分布 → 最近写入。
- **卡片**：搜索 / 状态分段 / 筛选在上；下方“左列表 + 右详情”（宽屏 ≥ 1101px）。点击行在右侧载入完整卡片详情（编辑 / 批准 / 驳回 / 软删 / 历史版本等原有操作都在），选中项写进哈希 `?sel=`（刷新可保持；Ctrl/⌘ 点击仍可新开）。窄屏隐藏右栏，点击仍整页跳转。
- **待审队列**：左列表（多选 + 批量条）+ 右“审阅台”（标题 40px 级、正文 Markdown、批准 / 驳回 / 查看全文）。批准 / 驳回与行内按钮、快捷键共用同一对函数（`approve` / `reject`，即原有确认框 + `queue/approve|reject` 接口）；处理完自动选中相邻一张。窄屏行内保留批准 / 驳回按钮。**驳回为审阅台内的行内理由框**（可选理由，≤500 字）：`r` 聚焦理由框，Enter 提交（Shift+Enter 换行），Esc 清空并取消，也可点“驳回”按钮；理由校验与 `queue/reject` 接口沿用原有；未输入理由等同于原对话框里留空。窄屏行内与批量驳回仍用原对话框。
- **整理中心**：计数大号数字格 → 参数 → “执行整理”（四步编号：1 选批次与上限 → 2 演练 → 3 确认执行 → 4 结果与回滚，仅反映状态）→ 预览详情折叠段。
- **知识图谱**：大标题 + 工具栏（搜索 / 标签 / 节点上限 / 视图选项）；画布为 80px 方格底、方角图例按钮、缩放条在画布右上；右侧面板为硬线分隔的侧栏；[[链接]] 边用强调色；节点仍按类型着色（数据编码）。
- **次要页面**（回收站 04 / 标签 05 / 健康 08 / 账户 09 / 活跃度 11 / 令牌 12 / 审计 13）：统一 `pageHead`（编号 + 英文标注 + 大标题）；内容放进 12 列网格 `.g12`（`c12/c7/c6/c5` 跨列，≤860px 单列）；分区带编号锚点（`secHead` 的 A1/B1…，或 `panel(..., {no})`）；表格为硬分隔线（上下 1px 墨线、表头等宽小写标注）。功能与原版一致。回收站每行有「立即删除」（危险色描边按钮，永久删除、跳过保留期），操作条有「立即删除所选」与「清空回收站」，均先弹确认框写明将永久删除 N 张卡且不可恢复；调用 `POST /admin/api/cards/purge`（见 docs/m3-admin.md）。
- **设置**（10）：A 审核 / B 去重与图谱 / C 保留与备份 / D 外观 / E 运行参数，左侧字母编号 + 说明，右侧字段（12 列 4+8）。
  - 运行时可改（存 DB `config` 表，`enforceAudit` 每次写卡现读，无需重启）：`auditMode`（all / none）、`auditExemptAgents`、`auditExemptKinds`。`PATCH /admin/api/settings`：admin 会话 + Origin + CSRF（与其他写接口同一入口）、只读模式 403、字段白名单（未知字段 400）、署名正则与 ≤50 个、类型必须在 `CAPTURE_KINDS`（或 `__all__`）、变更记 `write_log`（action=settings_update）与服务日志。
  - 只读展示（脱敏，需改环境变量/配置文件并重启）：去重参数（`MEMORY_DEDUP_*`，阈值默认 0.62）、回收站保留天数（源码常量 30）、备份份数与最近一次、批量上限、摄入闸门、蒸馏 LLM（仅“是否配置 / 模型名 / 主机名 / 密钥是否已设”，不含密钥、URL 凭据与路径）、`exposeTidyApply`、监听与代理开关、日志级别。**不返回** home / dbRoot / 配置文件等绝对路径。
  - 设计稿里有、代码里没有对应配置而未做：图谱相似边阈值（源码常量 0.42，不可配）、回收站保留天数的修改（常量）、去重阈值的修改（仅环境变量）、免审“取值范围”之外的字段。
  - 外观：主题（跟随系统 / 浅 / 深，既有机制）+ 强调色（朱红 / 钴蓝 / 森绿，`html[data-accent]` 覆盖 `--accent` 系令牌，深色用提亮变体），均只存 localStorage（键 `mh-theme` / `mh-accent`），`theme-init.js` 首帧前应用。

## 5.1 键盘快捷键（仅待审队列页，宽屏）

`j` / `k` 下一张 / 上一张；`a` 批准当前；`r` 聚焦行内驳回理由框（仅“待审”状态的卡；Enter 提交、Esc 取消）。焦点在输入框 / 文本域 / 下拉 / 复选框、带 Ctrl/⌘/Alt 修饰键、或已有对话框打开时不触发；页面顶部与审阅台按钮上有键帽提示。离开该页后监听自动卸载。

## 6 无障碍与响应式

- 跳到主要内容、路由切换后焦点交给主内容区、`scroll-padding` 防止粘性栏遮挡焦点、可见焦点环、`prefers-reduced-motion`。
- 抽屉导航：`aria-expanded`、Esc 关闭、关闭时 `visibility:hidden`（不可被 Tab 到）。
- 断点：1100（主从布局收起右栏）/ 860（抽屉导航）/ 560（手机，输入框 16px 防 iOS 放大）；`pointer: coarse` 时控件 ≥ 44px。

## 7 兼容约束（测试与 e2e 依赖的结构）

`.card-row`、`.card-link`、`.card-row-actions`、`.detail-head h1`、`.detail-actions button`、`.panel h2`、`.modal-foot button`、`.exec-grid ~ .edit-actions`、`.bulk-count`、`.tag-row`、`.syn`、`.token-plain` 等类名与按钮文案保持不变；JS 仍只经 `dom.js` 构造 DOM（无 innerHTML、无内联样式）。

## 9 兼容性与已知不足

- 兼容性实测（Playwright 1.62：WebKit 与 Firefox 153，1440 宽，浅/深）：总览 / 卡片 / 待审 / 整理 / 图谱 / 设置六页均无水平滚动；自托管 Archivo（400/500/700/800）与 IBM Plex Mono（400/500）两个引擎都加载成功；`:has()`、`color-mix()` 均受支持，设置页分段选择器与卡片行布局两引擎一致；应用自身控制台零报错（WebKit 唯一的 CSP 报错来自 Playwright 截图时注入的样式表，非应用问题）。未发现需要修的兼容问题。未测：真机 iOS Safari、旧版浏览器（`:has()` 需 Safari 15.4+ / Firefox 121+）。
- 图谱画布节点本身不可 Tab 逐个聚焦（以节点列表代替）。
- 图谱节点 >800 时仍是 O(n²) 力导向，未做聚类/LOD。
